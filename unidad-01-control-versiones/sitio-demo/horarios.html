cómo entregar una pratica

  1. traer los cambios con git pull
  2. crear la rama para la pratica con git switch -c "nombre-de-la-rama"
  3. trabajar y hacer comits atómicios
  4. subir la rama con git push
  5. abrir un pull request en githud
  6. revisar y fusionar el pull request
  7. volver a la rama principal(main)
  8. eliminar la rama de la pratica con git branch -d "nombre-de-la-rama"
